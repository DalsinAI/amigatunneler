# SDL Tunneler for GFOS

The AmiCradle Team's port of SDL Tunneler (two tanks dig for each other
underground, split screen, one keyboard) to GFOS: AmigaOS 3.2 with
GFOpenUp, 68040/68060 + FPU, on GFOpenUp's SDL 2 through sdl12-compat. It
ships as a release archive with an Installer and as the GFOpenUp part
Parts/Tunneler.

Upstream is fetched at build time (package/tunneler.lock); this repository
holds only the Amiga port. See [AMIGA_PORT.md](AMIGA_PORT.md).
